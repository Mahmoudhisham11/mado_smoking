زرار `m-btn` بنوع واحد من: `m-btn--primary` (ذهبي `gold` والنص `on-gold`)، `m-btn--secondary`، `m-btn--ghost`، `m-btn--danger`، `m-btn--whatsapp`.

- زرار أساسي واحد بس في كل نافذة أو شاشة (حفظ، تحصيل). الباقي ثانوي.
- على الموبايل الأزرار الأساسية `m-btn--lg m-btn--block` (48px) وفي شريط سفلي ثابت داخل النافذة، عشان الإبهام يوصل.
- `m-btn--danger` للحذف والصرف للعميل فقط. `m-btn--whatsapp` (#25D366) لإرسال واتساب فقط.
- أثناء الحفظ: `m-btn--loading` مع `<span class="m-spin">` ونص بالفعل ("جاري الحفظ")، ولا تغيّر عرض الزرار.
- الأيقونة قبل النص (على يمينه في RTL) بحجم 16px.

بتوفّر: النص (عربي)، نوع الزرار، أيقونة اختيارية.
