قائمة الأصناف جدول بسيط (الاسم، سعر البيع) مع بحث وتحديد متعدد (شريط ذهبي فيه "حذف المحدد"). على الموبايل كل صنف كارت: الاسم وسعر البيع.

**صفحة الصنف:** كروت الكمية في كل مخزن + الإجمالي، "آخر 3 أسعار توريد" بأرقام كبيرة بتاريخها (الأسعار بكسور عشرية لو لزم)، جدول التوريدات (التاريخ، المورد، الكمية، السعر)، وجدول المبيعات.
