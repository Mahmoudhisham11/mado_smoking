حقول بارتفاع `--tap` (48px) وخط 16px (عشان iOS ما يعمل zoom). الخلفية `surface-sunken` والحد `border-strong`.

- العنوان فوق الحقل دايماً (`label`)، والـ placeholder مثال مش عنوان.
- الأرقام والتليفون `m-input--num` (اتجاه LTR، أرقام لاتينية). مبلغ التحصيل والصرف `m-input--xl`.
- البحث عن صنف أو عميل: `m-combo` — الاقتراحات تحت الحقل، السطر فيه الاسم والكمية المتاحة، والجزء المطابق `mark` بالذهبي. أول نتيجة نشطة.
- الكمية `m-stepper`: أزرار − و+ بعرض 48px جنب خانة رقم، علشان تتظبط بإبهام واحد.
- الخطأ: حد `danger` ورسالة تحت الحقل بالكلام، مش باللون وحده.
- التفعيل/الإيقاف `m-switch`، والاختيار الثنائي `m-seg`.
