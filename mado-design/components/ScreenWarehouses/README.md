كروت المخازن (عدد الأصناف وإجمالي الكمية) وتحتها "تقرير التحويلات" بجدول فيه تعديل وحذف لكل تحويل.

**التحويل:** "من" و"إلى" فوق، وبعدهم سطور (الصنف + الكمية المتاحة في المخزن المصدر + stepper للكمية + حذف). منع اختيار نفس المخزن في الاتجاهين، ومنع كمية أكبر من المتاح (الحقل بيتلون أحمر ورسالة). زرار "تنفيذ التحويل" ذهبي في التذييل.
