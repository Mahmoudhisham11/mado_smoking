`m-tl`: خط رأسي ونقطة دايرية لكل حركة. النقطة خضراء (داخل) أو حمراء (خارج) أو ذهبية (تسوية)، ومعاها سهم وعلامة + أو − قبل المبلغ.

- السطر الأول: وصف الحركة والمبلغ. السطر التاني: التاريخ والوقت، والرصيد بعد الحركة. تحتهم شارة النوع.
- الأحدث فوق. نفس المكون لسجل العمليات في التقارير (فاتورة، سداد، تحويل، مصروف) من غير عمود الرصيد.
