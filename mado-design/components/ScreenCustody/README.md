كارت لكل موظف (صورة بحرف، الاسم، الدور، الرصيد). الكارت المختار بحد ذهبي، وتحته "سجل الحركات" Timeline.

- كل حركة: نقطة بلون الاتجاه (أخضر داخل، أحمر خارج، ذهبي تسوية)، الوصف، المبلغ بعلامة + أو −، التاريخ والوقت، **الرصيد بعد الحركة**، وشارة النوع (تحصيل، مصروف، تحويل، صرف، تسوية).
- **تعديل العهدة:** الرصيد في النظام، الرصيد الفعلي، والفرق (أحمر لو عجز، أخضر لو زيادة) + سبب التسوية إجباري.
- **التحويل بين العهد:** من، إلى، المبلغ، ومعاينة رصيد الطرفين بعد التحويل.
