الموردين للمالك فقط، ونفس فكرة العملاء بالظبط (قائمة كروت، صفحة بكروت وفلتر وجدول، نافذة سداد وكشف حساب). الفرق في الألفاظ: "مستحق له" بدل "مديونية عليه"، و"المدفوع للمورد".

**فاتورة الشراء:** السطر: الصنف ← **سعر التوريد** (وتحت الصنف سعر البيع الحالي والهامش للمقارنة) ← الكمية ← المخزن اللي هيدخل فيه. المدفوع بيتخصم من العهدة المختارة، والملخص بيوضح المستحق للمورد بعد الفاتورة.
