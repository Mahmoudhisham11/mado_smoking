كارت إحصائية `m-stat`: عنوان صغير، رقم كبير (`num-xl` على الكمبيوتر و22px على الموبايل)، وحدة ج.م، سطر توضيحي، أيقونة، وشريط 3px أعلى الكارت بلون النوع.

- الشريط: ذهبي (افتراضي) لمقاييس عامة، `m-stat--in` أخضر لفلوس داخلة، `m-stat--out` أحمر لفلوس خارجة أو مديونية، `m-stat--neutral` لأعداد مش مالية.
- الذهبي للإبراز: أغلب الكروت في الشاشة تبقى neutral أو ذهبي، مش كلها ملونة.
- زرار إخفاء الأرقام بيبدّل القيمة بـ `m-mask` (••••) وبيشيل الوحدة والسطر التوضيحي.
- الرقم بيتكتب دايماً بأرقام لاتينية وفاصلة الآلاف (186,525).
