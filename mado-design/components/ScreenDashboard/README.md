- زرار إخفاء الأرقام بيحوّل كل القيم المالية (إجمالي العهد، مصاريف اليوم) لـ •••• ويفضل الاختيار محفوظ على الجهاز.
- أعداد الأصناف والمخازن والعملاء والموردين بشريط رمادي (neutral)، والذهبي للعهد، والأحمر لمصاريف اليوم.
- الموظف مابيشوفش كارت الموردين ولا اختصار التقارير والموردين.
